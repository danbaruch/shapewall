Features

Built for messy, real thinking.

Lumen Notes connects what you write, so ideas find each other. Here is what is inside.

Offline first

Every note lives on your device first, then syncs when you are back online.

Backlinks

Type two brackets to link a note. Every link shows up on both ends.

Shared spaces

Invite a team, set who can edit, and keep private notes private.

Daily notes

A fresh page every morning, with yesterday's open tasks carried over.

Import anything

Markdown, plain text and exports from the big note apps.

Version history

Every change is kept for a year. Roll back a page in one click.
